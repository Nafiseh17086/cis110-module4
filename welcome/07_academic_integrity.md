# Academic Integrity in an AI-Assisted Course

> **DRAFT — to be finalized with the program.** This page explains how
> Northwestern's academic-integrity policy applies in CIS 110 specifically.
> The University policy always takes precedence.

## The short version

Submit only work you can **explain**, **reproduce**, and **account for**.

## Where the line sits in this course

This course is unusual: AI is forbidden in some weeks and *required* in others.
That means "did you use AI?" is never the whole question. The question is:
**did you use it the way this assignment allowed, and did you say so?**

**These are fine:**
- Using AI exactly as the assignment's permission level allows, and recording it
  in your reflection.
- Discussing ideas and approaches with classmates.
- Getting help in the Q&A discussion, office hours, or Learning Studios.
- Using examples from the assigned readings and Python documentation.

**These cross the line:**
- Using AI on an **Unassisted** assignment or a checkpoint, in any way.
- Asking AI to write or fix code on an **Explanation Only** assignment.
- Using AI at any level without recording it in your AI-Use Reflection.
- Submitting a classmate's code, or code copied from the internet, as your own.
- Giving your code to another student to submit.

## A useful test

Before you submit, ask yourself: *if my instructor asked me to explain any line
of this code, could I?* If the answer is no for any line, you are not ready to
submit it — regardless of where it came from.

## If you are unsure

Ask **before** you start. Nobody is penalized for asking what is allowed.
