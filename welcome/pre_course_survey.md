# Pre-Course Survey

*Complete the survey on Canvas before the first day of class. It takes about
five minutes, and it is not graded. The questions are listed here so you can
think about them first.*

Your answers shape what we focus on in the live sessions — for example, how
much time to spend on setup, and where to start with AI tools in Module 3.

1. **Program of study.** Which program are you enrolled in?
2. **Programming experience.** Which best describes you?
   - I have never written code
   - I've tried a tutorial or course but didn't get far
   - I've written small programs in some language
   - I program regularly
3. **Which languages, if any,** have you used before?
4. **AI tools.** Have you used an AI assistant (such as ChatGPT, Claude, Gemini
   or Copilot)?
   - Never
   - For everyday things, not for code
   - To help with code, occasionally
   - To help with code, regularly
5. **Your computer.** Windows, macOS, ChromeOS, or other? *(ChromeOS users,
   please also email your instructor — local setup is different.)*
6. **Goals.** What do you hope to be able to do by the end of the course?
7. **Worries.** Is there anything about this course you are nervous about?
8. **Availability.** Which times generally suit you for live sessions?
   *(Sessions are always recorded.)*
