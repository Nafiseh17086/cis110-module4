# Course Overview

## Course description

CIS 110 is an introduction to programming for students with no prior coding
experience, and the gateway course for the Data Science and Artificial
Intelligence specializations. Students learn to think computationally — to
break a problem apart, reason about it step by step, and express the solution
as working Python code. Alongside those foundations, students learn to work
with AI coding assistants the way practicing developers now do: specifying a
problem clearly, directing a tool toward it, and then reading, testing, and
correcting what comes back. The course treats these as two halves of one
skill. Students first build the ability to write and trace code unaided,
because that is what makes it possible to judge whether generated code is
correct; they then apply that judgment to increasingly substantial
AI-assisted work. By the end of the quarter, students have written a
quarter's worth of programs by hand, verified and repaired code they did not
write, and delivered a working application whose authored and assisted
portions they can account for and defend.

## Course objectives

By the end of this course, you will be able to:

1. Decompose a computational problem into a documented algorithm and
   implement it in Python independently, without generative assistance.
2. Apply core programming constructs — variables, control flow, functions,
   collections, files, and basic object-oriented structure — to produce
   correct and readable programs.
3. Read, trace, test, and debug programs, including code written by others or
   generated by AI tools, and demonstrate that the code behaves as specified.
4. Direct AI-assisted development deliberately by writing a clear
   specification, prompting against it, evaluating the output, and
   documenting what was accepted, rejected, and revised.
5. Evaluate the professional, ethical, and academic-integrity dimensions of
   AI-assisted software development, and communicate design decisions clearly
   to a technical audience.

## How the ten weeks are organized

| Module | Topic |
|---|---|
| 1 | Computational Thinking and Your First Programs |
| 2 | Control Flow and Algorithmic Reasoning |
| 3 | Functions, Decomposition, and Your First AI Collaboration |
| 4 | Lists, Strings, and Iteration Patterns |
| 5 | Dictionaries, Sets, and Structured Data |
| 6 | Files, Data, and Error Handling |
| 7 | Specification and Prompt-Driven Development |
| 8 | Testing, Debugging, and Verification |
| 9 | Program Structure: Objects, Modules, and Libraries |
| 10 | Final Project — Build, Verify, and Present |

## How you are assessed — 1000 points

| Assessment | Modules | Points |
|---|---|---|
| Weekly coding labs | 1–10 | 350 |
| AI-Use Reflection logs | 1–10 | 150 |
| Discussion forums | Welcome, 2, 4, 6, 8 | 100 |
| Checkpoint 1: Programming Fundamentals (AI-free) | 5 | 100 |
| Checkpoint 2: Code Reading and Verification (AI-free) | 8 | 100 |
| Final Project Proposal and Specification | 7 | 50 |
| Final Project Implementation and Documentation | 9–10 | 100 |
| Final Project Demonstration and Technical Walkthrough | 10 | 50 |

Expect roughly **10–13 hours per week**, including readings, videos, labs and
discussions. Weeks with a checkpoint or the final project run toward the top
of that range.
