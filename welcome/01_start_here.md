## What this course is about

You will learn to think computationally — to break a problem apart, reason
about it step by step, and express the solution as working Python code. You
will also learn to work with AI coding assistants the way practicing
developers now do: specifying clearly, directing the tool, and then reading,
testing, and correcting what comes back.

The first weeks are deliberately done **without** AI assistance. That is not
because AI is bad — it is because you can only judge whether generated code
is right once you can write and read code yourself. Everything later in the
course is built on that.

## Before Module 1 begins — your checklist

Complete all five before the first day of class.

- [ ] **1. Install Python 3.12 or later and Visual Studio Code**, then run the
      verification script: `python setup/verify_environment.py`.
      Follow [`setup/SETUP_GUIDE.md`](../setup/SETUP_GUIDE.md).
      If the script reports a problem you cannot fix, post its full output to
      the **Q&A** discussion.
- [ ] **2. Create a free account with the course's designated AI assistant**
      — **[assistant to be confirmed]**. Account creation only: you will not use
      it for coursework until Module 3.
- [ ] **3. Complete the pre-course survey** on Canvas. It asks about your
      programming and AI-tool experience, your program of study, and your goals.
      Your answers shape what we focus on in the live sessions.
      (The questions are in [`pre_course_survey.md`](pre_course_survey.md) if you
      want to think about them first.)
- [ ] **4. Read the [CIS 110 AI-Use Policy](06_ai_use_policy.md)** and complete the
      short acknowledgment quiz on Canvas. It is ungraded, but required before
      Module 1 opens.
- [ ] **5. Post an introduction** in the Welcome discussion — see
      [`10_discussions.md`](10_discussions.md).

**No textbook purchase is required.** All required readings are open access.
